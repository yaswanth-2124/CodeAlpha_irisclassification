Iris Flower Classification

Project Overview

This project uses Machine Learning to classify Iris flowers into three species:

- Setosa
- Versicolor
- Virginica

Technologies Used

- Python
- Scikit-learn
- NumPy

Dataset

The Iris dataset is loaded using Scikit-learn's built-in datasets module.

Steps Performed

1. Load the Iris dataset.
2. Split data into training and testing sets.
3. Train a K-Nearest Neighbors (KNN) classifier.
4. Predict flower species on test data.
5. Evaluate model accuracy.

How to Run

Install dependencies:

pip install scikit-learn

Run the program:

python iris_classification.py

Output

The program displays:
- Accuracy Score
- Classification Report
